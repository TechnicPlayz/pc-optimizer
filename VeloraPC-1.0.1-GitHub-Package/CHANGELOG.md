# Changelog

## 1.0.1
**Look and feel**
- Smoother, macOS-style motion: springy buttons, hover-lift cards, sliding toggles, staggered entrances, animated page transitions.
- Sidebar highlights the current page; Ctrl+1..8 jumps between pages.

**Storage Cleaner** (replaces Deep Clean)
- New categories: browser caches and (optional) graphics shader caches.
- Review each location and its biggest files before anything is deleted.
- Colour-coded breakdown of what can be freed. The same engine powers the Ultra boost.

**Administrator permissions**
- The boost checks whether admin rights would help, explains why, and lets you restart as administrator, continue without it, or cancel.
- Permission errors are detected and reported clearly instead of failing silently.

**Progress**
- Every progress bar now shows 0-100% and the task being done (scans, cleaning, RAM boost, repairs, updates, the boost itself).

**Reliability**
- Only one Velora window can run at a time.
- Health checks load in the background so pages never freeze.
- Safety guard: folders are checked against a protected list (Documents, Desktop, Downloads, Windows, ...) before any clean.
- Window size is remembered; "System" theme follows Windows live; a running boost can't be interrupted by accident.

**User Agreement**
- Rewritten in plain language, with the MIT license text; the "template" notices are gone.

## 1.0.0
- First release of the redesigned Velora PC.
- ULTRA ULTRA FAST PC one-click boost with real, measured results.
- RAM Boost, Deep Clean, Game Boost, PC Health, System Repair, History.
- Dark / light / system themes, onboarding, in-app updates, weekly auto-maintenance.
- Installer with uninstaller.
