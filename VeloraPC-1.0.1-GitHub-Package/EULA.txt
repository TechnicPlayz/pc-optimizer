VELORA PC - USER AGREEMENT

In plain English: Velora PC is free, open-source software. Use it, share it,
and change it. It tidies your PC, but you use it at your own risk. Details below.

Source code: https://github.com/TechnicPlayz/pc-optimizer


1. WHAT VELORA DOES TO YOUR PC

  - Deletes temporary files, browser caches and Recycle Bin contents, but only
    from a fixed list of system cache locations. It never touches your
    Documents, Desktop, Downloads, Pictures, Music or Videos.
  - Frees memory that apps are not using. No program is closed.
  - Changes a few Windows settings (Game Mode, Game Bar capture, power plan).
    Your original settings are saved first, and you can restore them in Game Boost.
  - Runs Windows' own repair tools (SFC and DISM) when you ask, and a quick
    health check during Ultra boost.

You can review everything in Storage Cleaner before it is deleted.


2. ADMINISTRATOR ACCESS

A few features need administrator rights. Velora asks first, explains why, and
only restarts as administrator if you say yes.

for losses that come from using the software.


4. PRIVACY

Velora collects no telemetry and sends nothing about you or your PC anywhere.
The only network request is the optional update check, which asks GitHub for
the latest version number. Settings, history and logs stay on your PC.


5. UPDATES

Updates are optional. Velora only downloads and installs one when you click the
update button, and it checks the file's SHA-256 fingerprint first.


6. QUESTIONS AND PROBLEMS

Open an issue at https://github.com/TechnicPlayz/pc-optimizer/issues.
In the app, Settings > Logs > Export logs creates a file you can attach.
